# Myosotis 0.0.1

The first public native Windows MVP: capture, scribble, and paste.

## Download and run

1. Download **Myosotis-0.0.1-windows-x64.zip** below.
2. Extract it and run `Myosotis/myosotis.exe`.
3. Press **Ctrl+Alt+S**, select a screenshot or white canvas, annotate, and press **Enter** to copy.

Requires Windows 11 x64. The app is portable, unsigned, and needs no additional application runtime. It stays in the notification area; right-click its flower icon to quit.

## Scoop

```powershell
scoop bucket add myosotis https://github.com/nekoium/Myosotis
scoop install myosotis/myosotis
```

This uses the project's own bucket. The app is not yet listed in the WinGet or Chocolatey community catalogs.

## Included

- Global shortcut and immediately frozen desktop capture.
- Screenshot regions, whole-monitor capture, and white canvases.
- Pen, arrows, rectangles, and numbered marks (`1`–`4`).
- Space input, undo/redo (`Z` / `Y`), and hover-then-drag selection resizing.
- Bitmap and PNG clipboard output; Escape preserves the previous clipboard.
- Native Rust, Win32, Direct2D, DirectWrite, and Windows image encoding.

## Validation and limits

Four Rust tests, Clippy, and the native Windows integration check pass. A sketch was visibly pasted into Microsoft Paint during MVP validation. Interactive checks require an idle desktop; two checks failed on earlier runs before the complete passing run for this version.

Mixed-DPI multi-monitor setups, HDR, protected content, and physical stylus hardware have not been fully validated. Pressure, erasers, configurable styles, and individual screen-reader toolbar controls are not implemented. macOS and Linux are planned.
